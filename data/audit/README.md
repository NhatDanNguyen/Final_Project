# Data Audit and Validation

This directory contains the validation outputs generated by the KNIME data-processing workflow.

## Purpose

The audit files provide evidence of data quality checks performed during data preparation. They help verify that the processed datasets preserve the original source information and that calculated results are consistent with published reference figures.

## Validation categories

- **National reconciliation:** Compares calculated annual hospitalisation totals against published national figures.
- **Duplicate detection:** Identifies potential duplicate records.
- **Count validation:** Identifies missing, invalid or unexpected hospitalisation values.
- **Suppression handling:** Preserves suppressed and missing values without incorrectly converting them into zero.
- **Source integrity:** Retains information about the original values used during processing.

## How to use

1. Inspect the generated audit outputs.
2. Investigate any unexplained discrepancies.
3. Confirm that validation results are acceptable before using the processed datasets in the website.

## Important notes

These files are intended for internal data-quality verification and project transparency. They are not directly consumed by the website's visualisations.
